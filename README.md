# Currículo Online

Projeto desenvolvido com HTML e CSS para apresentar meu currículo de forma online e responsiva.

## Acesse o site

🔗 https://sagaszzz.github.io/curriculo-web/

## Sobre o projeto

Este projeto tem como objetivo disponibilizar meu currículo em formato web, apresentando minhas informações profissionais, formação, habilidades técnicas e projetos desenvolvidos.

A página foi criada com foco em simplicidade, organização visual e fácil acesso para recrutadores e empresas.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Funcionalidades

- Apresentação profissional
- Seção de objetivo
- Formação acadêmica
- Habilidades técnicas
- Projetos desenvolvidos
- Links para GitHub e LinkedIn
- Página publicada com GitHub Pages
